# Frontend

Next.js 16 (App Router) + React 19 + TypeScript + Tailwind CSS 4.

Setup, commands, env vars and the frontend↔backend integration pattern are
documented in the [project README](../README.md).

```
src/app/          Routes and pages
src/components/   Reusable UI (Header, Footer, Card, Container)
src/lib/api.ts    Typed client for the FastAPI backend
```
